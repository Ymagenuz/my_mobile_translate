# SnipDo Translate Android 版

[English](README.md) | **简体中文**

Windows 版 [SnipDo Translate](https://github.com/Ymagenuz/my_snipdo_translate) 的 Android 对应版本：使用你自己的 OpenAI 兼容 API Key 进行翻译、查词和 OCR，提示词、接口和行为都与桌面版一致。需要 Android 8.0 或更高版本；屏幕选词需要 Android 12 或更高版本。

## 翻译方式

- **在任意应用中选中文字**，然后在选择菜单里点 **SnipDo Translate**，结果会以面板形式显示在该应用上方。
- 把文字或图片**分享**给本应用。
- 快捷设置中的**翻译剪贴板**磁贴。
- **屏幕选词**磁贴：直接从屏幕上选词。
- 应用内的**相机**和**照片**，使用与屏幕选词相同的画笔。
- 也可以在应用内输入。短词会自动查词。

## 屏幕选词

下拉通知栏，点按**屏幕选词**。屏幕会被冻结，看起来没有变化，只多了一个悬浮工具栏。文字在手机上完成识别，在你操作之前不会显示或发送任何内容。

| 工具 | 作用 |
|---|---|
| ✎ 文字笔 | 点按切换单词选中状态。拖动按阅读顺序选中两端之间的所有单词。 |
| + 加选笔 | 加选笔画碰到的所有单词，与阅读顺序无关。再点一次可调整笔宽。 |
| − 减选笔 | 取消笔画碰到的所有单词，有独立的笔宽。 |
| ◯ 套索 | 圈出区域，加选其中的单词。 |
| ¶ 段落笔 | 点按切换整段。 |
| ▭ 区域笔 | 拖出矩形，由视觉模型只读取该区域，适合识别不了的内容：俄文、手写、艺术字。 |

工具栏还有撤销、重做、全选、清除、阅读顺序/选择顺序切换和识别语言（中、A、あ、한）。按住 ⠿ 拖动工具栏，它会贴靠最近的一侧并记住位置，也可以收起成小圆块。双指可以缩放和平移冻结的图像。点**翻译**或**复制**确认。关闭结果会回到选择状态；按返回键或 ✕ 回到正在运行的应用。

### 一次性设置

屏幕选词是一个 Android 无障碍服务，这样每次截屏都不用再询问。

1. 在应用中打开**设置 → 屏幕选词 → 无障碍设置**，开启 **SnipDo 屏幕选词**。
2. Android 会阻止从应用商店以外安装的应用开启此项。如果提示这是受限设置，请打开**应用信息**，点按 **⋮** 菜单，选择**允许受限设置**，然后重试第 1 步。不同手机厂商的菜单有所不同。
3. 把**屏幕选词**磁贴添加到快捷设置。

有些手机厂商会为省电而停止后台服务。如果磁贴失效，请在电池设置中为本应用设置例外。

## 隐私

- 无障碍服务只能截屏，且只在你点按磁贴时截屏；它的配置使其无法读取其他应用的内容。
- 截图只保存在内存中，绝不写入存储或历史。识别在手机上完成。
- 在你确认之前不发送任何内容，确认后也只发送你选中的文字。区域笔和“用 AI 读取”只发送相应图片。
- API Key 使用 Android Keystore 中的密钥加密。备份和设备间迁移均已关闭。
- 应用已停用 ML Kit 自带的使用情况上报：上传通道被移除，记录的事件会在手机上直接丢弃。
- 检查更新时只向 GitHub 询问最新版本，只会透露应用版本号。

## 与桌面版的区别

- 自定义接口必须使用 HTTPS，因为明文 HTTP 会让 API Key 经过共享网络传输。
- 暂未包含：LaTeX 排版（公式在翻译时受保护并以源码显示）、**定位译文**、输入框的 Markdown 排版。
- 屏幕识别不支持俄文，请使用区域笔。
- 更新时会在浏览器中打开发布页面，而不是在应用内安装。

## 构建

工具链位于 `D:\Android`，按命令使用，不修改系统：`jdk-21` 是 JDK 21，`Sdk` 是 SDK，`gradle-home` 是 Gradle 缓存。可通过 `SNIPDO_ANDROID_ROOT` 指定其他位置。

```powershell
.\scripts\gradle.ps1 testDebugUnitTest          # 在电脑上运行测试
.\scripts\gradle.ps1 connectedDebugAndroidTest  # 在设备或模拟器上运行测试
.\scripts\gradle.ps1 assembleDebug              # 调试版 APK
.\scripts\gradle.ps1 assembleQa                 # 优化后的代码，可安装到模拟器
.\scripts\test_summary.ps1                      # 查看实际运行的测试数量
```

发布前务必检查 `qa` 构建。发布版会压缩代码，可能破坏调试版中正常的功能：ML Kit 就曾因此崩溃，直到 `app/proguard-rules.pro` 保留了它所需的内容。

`scripts/generate_golden.py` 记录桌面版的提示词和文本规则，供测试对比；桌面版有改动时请重新运行。`scripts/mock_llm.py` 是本地模拟 API，可在没有真实 Key 时做端到端检查。

## 签名

发布版 APK 使用 `D:\Android\keys\snipdo-release.jks` 签名，密码保存在被 git 忽略的 `keystore.properties` 中。**请把这两个文件备份到安全的地方。** 一旦丢失，今后的 APK 将无法更新已安装的应用。

## 发布版本

1. 在 `app/build.gradle.kts` 中提高 `versionCode` 和 `versionName`，并在两份更新日志中添加条目。
2. 运行 `.\scripts\build_release.ps1`。
3. 创建标签为 `v<版本号>` 的正式 GitHub Release，上传 `dist\SnipDoTranslate.apk` 和 `dist\SnipDoTranslate.apk.sha256`。

应用最多每 6 小时检查一次本项目的最新版本，有新版本时会在**设置**旁显示 ⬇。
